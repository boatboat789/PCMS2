# commands/ — Slash Commands (ยังไม่ได้ใช้งาน)

โฟลเดอร์นี้ยังว่างอยู่ — scaffold ไว้ล่วงหน้า (template กลาง — copy ไปทุกโปรเจกต์ในเวิร์กสเปซ)

## ต่างจาก `.claude/prompts/` ยังไง

ทุกโปรเจกต์มี `.claude/prompts/` อยู่แล้ว (fix.md, implement-feature.md, refactor.md, review.md
+ บางโปรเจกต์มีเพิ่มเฉพาะทาง เช่น sync-doc-index.md) ซึ่งเป็น **เอกสารอ้างอิง** ตามตาราง
"Prompts Library" ใน `CLAUDE.md` — ต้องเปิดอ่านเองหรือ copy เนื้อหาไปวางในแชท ไม่ใช่ฟีเจอร์ของ
Claude Code โดยตรง

`commands/` คือ **slash command จริง** ของ Claude Code — ไฟล์ `.md` แต่ละไฟล์ในนี้เรียกใช้งานด้วย
`/ชื่อไฟล์` ในแชทได้ทันที (เช่น สร้าง `deploy-check.md` แล้วพิมพ์ `/deploy-check` เรียกใช้ได้เลย
โดยไม่ต้องบอกบริบทซ้ำ)

## จะเพิ่มยังไง

สร้างไฟล์ `.md` ในนี้ 1 ไฟล์ต่อ 1 คำสั่ง เนื้อหาในไฟล์คือ prompt ที่จะรันเมื่อเรียกคำสั่งนั้น —
ดูตัวอย่างรูปแบบเนื้อหาได้จากไฟล์ใน `.claude/prompts/` ที่มีอยู่แล้ว (โครงเดียวกัน แค่เปลี่ยนวิธีเรียกใช้)

**ยังไม่มีไฟล์จริงในนี้** — เป็น template กลาง รอแต่ละโปรเจกต์ตัดสินใจว่าจะย้าย/เพิ่ม command
ไหนก่อนตามความเหมาะสมของโปรเจกต์นั้น
